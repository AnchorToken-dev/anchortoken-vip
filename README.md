# Anchor Token — anchortoken.vip

Official dual-chain site for Anchor Token (AnchorToken-dev / Mark).

- **Home `/`** — Robinhood-chain launch (primary, coming soon)
- **`/solana`** — Solana / Pump.fun track (live, still advertising)

Stack: Vite + TanStack Start + Nitro + Tailwind (same family as Memecoindev).
